**NOTIZ-APP**

hier habe ich eine Notiz-App gebaut. 
Sie kann neue Notizen aufnehmen, speichern und wieder löschen. 
Auch das Datum ist ersichtlich, wann die Notiz erstellt wurde. 
habe wieder mit LocalStorage gearbeitet, damit die Notizen auch nach Schliessen der App bestehen bleiben. 

TechStack
- **Frontend:** HTML5, CSS3
- **Logik:** JavaScript
- **Datenbank:** Browser LocalStorage
